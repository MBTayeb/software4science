Why Python? Because it is an open source software for all major operating systems with an extremely large ecosystem covering almost everything from web frameworks to scientific programming. Python is interpreted, not compiled and therefore usally not as fast as Fortran or C/C++ for number crunching applications, but it is fully object-oriented with dynamic typing. We already mentioned the Anaconda environment above, as well as the PyCharm IDE and Jupyter notebooks (guess what the 'pyt' stands for). BTW: If the question turns up; Python 2 is outdated, use Python 3.

Python basics are similar to most scripting languages, 'container' data types allow for lists etc., indexing starts like for C/C++ at zero. A 'def' statement is used to define functions, and they, as well as all other control structures, are delimited by indentation. This means you have to do proper indentation (four spaces), otherwise your functions and control structures won't work, but you don't need any end statements. Python is as mentioned above proper object-oriented, which means that everything in Python is an object (e.g., a=1 corresponds to an object a of class int with the value 1).

How these concepts are put to use is easy to learn when learning to program in Python, for instance with the following tutorials.
