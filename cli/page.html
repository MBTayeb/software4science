The normal way of interacting with the computer is using Graphical User Interfaces (GUIs), i.e. by interacting with windows and clicking with the mouse. But under the hood, all that we do with the mouse is allowed by pre-written programs. In other words, it is code that drives the computer. To make use of this, we use the interface that predated GUIs: the Command-Line Interface (CLI). When using a CLI, instead of clicking you write a command to the computer.

Technically, the command-line interface is tyically carried out through a terminal that allows the user to type text which then gets forwarded to a shell. A terminal or a terminal emulator is the graphical window seen on the screen that handles this. The shell is responsible for interpreting these commands. Which is why shells are also called command-line interpreters.
