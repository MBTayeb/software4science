Prompt customization is one of those optional things that make programming more enjoyable. One notable tool for this purpose is Oh-My-Posh. It customizes the prompt you see in the terminal very easily. You can pick one of many themes. Since it changes the prompt, each shell (PowerShell, cmd.exe, Bash ...) used within the computer needs a separate setting. Typically, people add it to the shell profile, which is a file used to configure what should be loaded in the start of a new shell session. If one wants to use it within a WSL, one would need to install it in WSL. (If WSL is still unknown to you, no worries! It will be discussed in the following chapter.)
