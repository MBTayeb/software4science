Online resources for quickly looking up syntax of different languages:

https://learnxinyminutes.com/
-- Learn X in Y minutes, where X is one of the many available languages to choose from.
https://www.algorithm-archive.org/
-- The Arcane algorithm archive It's a community driven archive aiming to provide a guide into all the important algorithms in all languages.
https://quickref.me/
-- QuickRef: online cheat sheets for many programming languages

Easy offline documentation:
https://zealdocs.org/
-- Zeal: "offline documentation browser for software developers"
https://github.com/smsearcy/zeal-feeds
-- Zeal-feeds: a simple CLI tool "for adding user contributed docsets to Zeal".
https://devdocs.io/offline
-- DevDocs: offline webapp for ducs One should open the site and download the docs that one needs Then, the website can be accessed even when there is no internet access
