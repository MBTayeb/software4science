Jupyter Notebooks (formerly IPython) is a web-based environment for writing and executing Jupyter notebook JSON (.ipynb) files. It offers input/output cells with code, text incl. mathematical formulas, plots, media, which in addition can be converted to standard output formats like HTML, LaTeX, PDF, Markdown, Python etc. It is arguably the most commonly used environment for solving data science tasks in Python. Alternative supported languages include R, Julia etc. The kernel of a Jupyter notebook is the computational (usually cloud) resource to execute code. Eachcell of a notebook is a container for code to be executed, or text/graphs/urls to be shown, etc. Using Markdown syntax, text can be formatted.

The Jupyter Notebook at the bottom of this work unit illustrates how Jupyter Notebooks work.

At the University of Münster, there is a 'Jupyter Hub', a multiuser server for Jupyter notebooks sessions as ’pods’ in the Kubernetes cluster 'ZIVkube' on the Uni Cloud Münster. When logging in you can choose CPU/RAM resources and a notebook 'image' with preinstalled features for various domains, including eScience, software development, and data analysis. From these notebooks you have access to the HPC system Palma II, as well as the Uni Cloud. Your JupyterHub home is accessible as network share within the university network.

Upcoming is a 'Binder Hub' hosted by the university. Final comments:

When using Jupyter Notebooks, resist the urge to 'think in cells' instead of functions or classes.

Also keep in mind that depending on how you want to reuse your code, Jupyter Notebooks might not be the optimal tool for the job.
